# 验收清单

逐项勾选，全过才进部署；不过的项记录问题与位置。

## 功能走查
- [ ] 每个页面的每条交互实际点过（链接、表单、按钮、跳转）
- [ ] 表单校验：空值、错误格式、提交成功与失败反馈
- [ ] 异常路径有提示，不白屏不静默

## 响应式
- [ ] 移动 / 平板 / 桌面三档实际看过
- [ ] 无横向滚动条，导航在窄端可用

## 可访问性
- [ ] 键盘能走完核心流程
- [ ] 文本对比度达标，图片有替代文本

## 性能与质量
- [ ] 控制台零报错
- [ ] 图片压缩、无多余依赖
- [ ] SEO 基础：每页 title/description、语义化标签

## 与需求对账
- [ ] 需求简报逐条核销，差距已说明
