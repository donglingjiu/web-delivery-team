# UI/UX 设计交付物规范

本阶段产出一个《设计简报》，确认后才进前端编码。

## 1. 站点地图

- 页面树：每页一行（页面名 / 路径 / 一句话职责）。
- 标注核心转化路径（用户从哪进、到哪完成目标）。

## 2. 每页线框

- 区块列表自上而下：导航 → 主视觉 → 内容区 → CTA → 页脚。
- 每区块标注：内容要点、层级、主要操作；不画像素，只定结构。

## 3. 设计令牌表

| 令牌 | 约定 |
|---|---|
| 色板 | 主色 / 强调色 / 中性色阶（给 hex） |
| 字体 | 标题字体 / 正文字体 / 字号层级（3-4 档） |
| 间距 | 基础单位与倍数序列 |
| 圆角/阴影 | 各 2-3 档 |
| 断点 | 移动 / 平板 / 桌面 |

## 4. 组件清单

按钮、表单、卡片、导航栏、页脚、列表项——每个组件给状态（默认/悬停/禁用）。

## 5. 可访问性底线

对比度达标、键盘可达、图片有替代文本。

审美方向与 frontend-builder 的 references/design-guide.md 对齐：有意图、有记忆点、反模板。
