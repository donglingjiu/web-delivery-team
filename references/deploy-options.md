# 部署决策树

## 先判环境

- 本机/自有服务器 → 正常部署流程。
- 容器/沙箱 → 按 frontend-builder 的沙箱规则：只交付构建产物与部署指引，绝不报容器内地址。

## 静态站

1. `npm run build` 出产物。
2. 托管任选其一：对象存储静态托管 / 静态站点平台 / Nginx 指到产物目录。
3. 交付：访问地址 + 产物路径 + 更新方式（重新构建覆盖即可）。

## 全栈应用

1. 后端依赖装齐、环境变量配好（密钥不进代码）。
2. 数据库迁移先跑。
3. 进程守护 + 反向代理 + HTTPS。
4. 交付：地址、账号、回滚方式（上一版本产物/镜像保留一份）。

## 上线前最后一遍

- [ ] 访问地址在目标网络环境真实打开过
- [ ] 无 localhost / 内网 IP 出现在交付说明里
- [ ] 出问题找谁、怎么回滚，写清了
